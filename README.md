# 🏔️ ComfyUI-DJ_align

> 版本 `260911-073501` · 作者：大江

ComfyUI 节点对齐工具，框选节点后弹出对齐面板，支持六向对齐、双向分布、等宽等高。

## ✨ 功能速览

- **六向对齐**：左、右、顶、底、水平居中、垂直居中
- **双向分布**：横向等距分布、纵向等距分布
- **等宽/等高**：对齐最大值或最小值
- **智能分组**：自动按坐标聚类，多组节点分别对齐
- **两种模式**：驻留（固定面板）/ 选中后显示（跟随鼠标上方弹出）
- **可拖拽**：通过分割线拖动面板到任意位置

## 一眼看懂

| | 能力 | 说明 |
|---|------|------|
| 对齐 | 左/右/顶/底/水平居中/垂直居中 | 框选 ≥2 个节点即可用 |
| 分布 | 横向/纵向等距 | 自动计算间距 |
| 尺寸 | 等宽/等高（最大/最小） | 统一选中节点宽度或高度 |

## 安装

```
custom_nodes/
└── ComfyUI-DJ_align/
    ├── __init__.py
    └── node_info.js
```

安装后重启 ComfyUI，右上角出现对齐面板。右键面板可切换驻留/选中后显示模式。
